## Completed checks

- Original SVG, PNG frames and nine-size ICO generated; 256px icon inspected.
- Source verifier passed: 62 Rust files, four workspace packages, formatting,
  native resources/icons, manifests, extension JS/PNG and PowerShell syntax.
- Optimized locked/offline Windows build passed for GUI and native host with
  `-C target-feature=+crt-static`. First build exposed the bindings' omitted
  NIN_KEYSELECT constant; shellapi.h supplied its exact definition, then the
  incremental build passed. One existing unused `show_duplicate` warning remains.
- Both application executables report product Rusty Download Manager and version
  0.1.0. PE inspection confirms x64 and no external Visual C++ runtime DLL imports.
- Existing Inno Setup 6.7.3 compiler reused; its original installer has a valid
  Authenticode signature. A proposed silent compiler installation was rejected by
  automatic approval review and was not performed.
- Inno setup compilation passed; setup reports Rusty Download Manager 0.1.0.
- Portable archive has 291 entries and extension archive has 14. ZIP content and
  CRC checks matched the staged files. Both staged executables matched the build.
- All 145 resolved Windows dependency records have bundled upstream license files.
- GPT-6.1 Sol review found one Important shutdown issue; the callback now sets a
  cloned engine client's atomic shutdown signal immediately, independent of modal
  GUI loops and command queue capacity. The reviewer confirmed this correction.
  Title/About version consistency was also corrected.
- `git diff --check` passed. No development server or test suite was run.

## Live acceptance not run

Installer execution, upgrade/uninstall, sign-in startup, Explorer restart, tray
interaction, hidden-instance activation, modal-dialog sign-out, actual downloads,
Chrome handoff, completion actions and DPI/layout comparison were not exercised.
These source/build/package checks are not a substitute for that live acceptance.

The installed native host was still running when packaging finished. Close Chrome
and exit Rusty before running setup; setup contains both mutex and process-path
guards and will not stop active downloads for the user.

See the [user guide](USER_GUIDE.md) for installation, background use, Chrome's
one-time approval and the session-only history limitation.
