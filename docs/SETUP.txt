Rusty Download Manager 0.2.1

Rusty runs in the Windows notification area after setup. Closing the manager
hides it; use the tray icon to reopen it or Exit. Sign-in startup is selected
by default on the previous setup page. Windows must be awake and signed in.

Chrome, Brave, Edge and Firefox each need their own extension and one-time
approval. The installer offers a Chrome connection helper. Other browsers can
be connected from Options > General > Add browser. Firefox distribution also
requires signing. Existing owned integration and preferences are preserved.

Unfinished downloads are restored held for review. A changed server response
or saved partial can require a fresh address or explicit restart.
This release is unsigned. No automatic publishing or updating is enabled.
